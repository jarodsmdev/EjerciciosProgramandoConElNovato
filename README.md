# Playlist de Java - Programando con el Novato

Bienvenido al repositorio de **Programando con el Novato**. Este repositorio contiene los códigos y ejercicios realizados en los videos de la serie de YouTube [Playlist de Java - Programando con el Novato](https://youtube.com/playlist?list=PL0OKXi7iFPGqMMU78vaCvtSAOjS1ZNxbK&si=zum3cwzNq_ITUR17).

## Descripción

La serie de videos en esta playlist cubre una variedad de temas fundamentales y avanzados en el lenguaje de programación Java. A través de ejemplos prácticos, se exploran conceptos como:

- **Herencia** en Java
- **Polimorfismo** y su aplicación
- Creación de **interfaces gráficas** usando Java Swing y JavaFX
- Uso de **interfaces** y manejo de eventos con **ActionListener**
- Manejo de **hilos (Threads)** en Java para concurrencia

Cada video viene acompañado de código fuente que puedes utilizar para practicar y experimentar por tu cuenta. Este repositorio es un complemento ideal para los videos, ya que contiene todos los ejemplos y ejercicios discutidos.

## Contenidos

Los siguientes temas se cubren en la playlist:

1. Introducción a Java y primeros pasos
2. Estructuras de control y ciclos
3. **Herencia**: Conceptos y ejemplos prácticos
4. **Polimorfismo**: Implementación y usos
5. Creación de **interfaces gráficas** con **Java Swing**
6. Introducción a **JavaFX**
7. Uso de **ActionListener** para manejar eventos
8. **Threads** en Java: Concurrencia y paralelismo
9. Ejercicios y proyectos finales
